# Support

- Read the root README and the README inside the relevant architecture folder.
- Run `python -m famous_cnns --help` and `python -m famous_cnns info MODEL`.
- Search existing GitHub issues before opening a new one.
- Use the bug-report template and include environment details plus a minimal reproduction.

Questions and usage problems may be opened as GitHub discussions or issues. Vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
