# Changelog

This project follows [Semantic Versioning](https://semver.org/). Dates use ISO 8601.

## [Unreleased]

### Added

- Repository governance, security, contribution, support, and community files.
- GitHub Actions for tests, packaging, CodeQL, dependency review, and Docker builds.
- Dependabot configuration for Python, GitHub Actions, and Docker.
- Root and architecture-specific training and inference CLIs.
- Multi-stage Docker image and Docker Compose development service.

## [0.3.0] - 2026-07-14

### Added

- Unified `famous_cnns` model factory and `CNNOrchestrator`.
- Automatic input-channel adaptation, optimizer selection, training, evaluation, prediction, checkpoints, and visualizations.
- Registry for LeNet, AlexNet, VGG, Inception, ResNet, U-Net, MobileNet, and EfficientNet.
